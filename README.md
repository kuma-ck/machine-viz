# Machine Viz - 機器情報可視化

機種シリーズ・機種番号・機番に紐づく特性値データを検索・可視化するWebアプリケーション。

## セットアップ

```bash
# 依存関係のインストール
uv pip install -e .

# 開発サーバー起動
uv run uvicorn app.main:app --reload --port 8000
```

## 機能

- **機番検索**: 条件指定による機番一覧表示・ランダムサンプリング
- **時系列表示**: 最大5台の機番の特性値推移をグラフ表示
- **断面データ表示**: 月別ヒストグラム・グループ比較
- **表形式表示**: データをテーブル形式で表示
